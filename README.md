# STEMediaHub

STEMediaHub is an ultimate learning guide for STEM students, providing comprehensive resources and materials for various subjects including:

- Earth Science
- Oral Communication
- Pre Calculus
- Physical Education
- General Mathematics
- Personal Development
- 21st Century Literature
- Komunikasyon at Pananaliksik
- Empowerment Technology

## Features

- Modern and responsive design
- Interactive user interface
- Easy navigation
- Subject-specific learning materials
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through different subjects using the main menu
